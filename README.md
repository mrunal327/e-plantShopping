# e-plantShopping

## Project Description

e-plantShopping is a plant shopping application called Paradise Nursery. It allows users to browse different plants, view product information, add plants to a shopping cart, update quantities, remove items, and view the total cart amount.

## Features

- Browse plant products
- View plant names, prices, categories, and images
- Add plants to the shopping cart
- Remove plants from the cart
- Update product quantities
- Calculate the total cart price
- User-friendly plant shopping interface

## Technologies Used

- React
- JavaScript
- CSS
- Redux
- GitHub

## Usage

Users can browse the available plants, add plants to the shopping cart, change quantities, remove products, and view the total price of their cart.
